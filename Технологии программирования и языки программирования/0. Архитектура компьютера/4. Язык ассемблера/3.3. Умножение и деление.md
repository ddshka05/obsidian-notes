### Операция умножения
Для операции умножения существует две инструкции

```x86asm
mul   // умножение для беззнаковых
imul  // умножение для знаковых
```

Инструкция `mul` использует содержимое регистра `RAX` в качестве одного из множителей. Результат умножения сохраняется в два регистра: старшую часть результата — в `RDX`, а младшую — в `RAX`. Это необходимо, так как результат может быть больше, чем размер одного регистра.
- **Умножение 8-битного значения:** результат в `AX`.
- **Умножение 16-битного значения:** результат в `DX:AX`.
- **Умножение 32-битного значения:** результат в `EDX:EAX`.
- **Умножение 64-битного значения:** результат в `RDX:RAX`.
То есть если результат будет больше, чем 64 битное число, то тогда старшие биты пойдут в `rdx`. 

Инструкция `imul` используется для умножения чисел со знаком. Эта инструкция имеет несколько форм:
1. **Один операнд:** умножение содержимого `RAX` на операнд, результат в `RAX` (и в `RDX`, если результат больше 64 бит).
2. **Два операнда:** умножение одного регистра на другой. Результат сохраняется в первый регистр.
3. **Три операнда:** результат сохраняется в третий операнд, а два других задают множители. (один из операндов должен быть числовым литералом!)

**Пример для `imul` с двумя операндами:**

```x86asm
section .text
global _start

_start:
    mov rbx, 6
    imul rbx, 4      ; результат сохраняется в RBX, то есть RBX = 6 * 4

    mov rax, 60      ; syscall: выход
    syscall
```

**Пример для `imul` с тремя операндами:**

```x86asm
section .text
global _start

_start:
    mov rcx, 2
    imul rsi, rcx, 9 ; RSI = RCX * 9

    mov rax, 60      ; syscall: выход
    syscall
```
### Операция деления
Для выполнения операций деления целых чисел используются инструкции `div` и `idiv`. Инструкция `div` предназначена для деления беззнаковых значений, тогда как `idiv` применяется к числам со знаком. Обе инструкции работают только с одним операндом, который указывает делитель. Операндом может быть регистр или область памяти, разрядность которой определяется требуемым типом деления: 8-, 16-, 32- или 64-битным.

В общем, эти операции используют разной разрядности регистры, то есть например для 64 битной арифметики, они берут RDX:RAX, при вызове инструкции деления, в вызываемый регистр нужно положить делитель, а RAX делимое, и по итогу ожидаем в RAX частное, а в RDX - остаток от деления. (чет остаток не выводится)
#### Инструкция `div`
- Деление беззнаковых чисел.
- Работает с делителями разных разрядностей: 8-битными, 16-битными, 32-битными и 64-битными.
- Частное размещается в младшем регистре, остаток — в старшем.
#### Инструкция `idiv`
- Деление со знаком.
- Для корректного деления знаковых чисел необходимо расширить знак в старшую часть делимого (например, с помощью инструкции `cqo` для 64-битных чисел).
### Важные моменты:
1. **Подготовка регистров:**  
    При делении необходимо правильно подготавливать регистры. Например, для деления 32-битных чисел нужно обнулить старшую часть регистра `EDX` перед выполнением операции `div`, чтобы избежать ошибок.
2. **Регистр для деления:**  
    Все деления (и для `div`, и для `idiv`) выполняются с операндом, который указывает только делитель. Все данные для деления должны быть в соответствующих регистрах (например, в `RDX:RAX` для 64-битного деления).
3. **Сигнальные флаги:**  
    При умножении с помощью `mul` флаги переполнения (OF) и переноса (CF) могут быть установлены, если результат операции выходит за пределы доступных бит.
4. **Конвертация знаков:**  
    Перед использованием `idiv` для знаковых чисел важно использовать инструкции расширения знака (`cbw`, `cwd`, `cdq`, `cqo`), чтобы гарантировать правильную арифметику.
